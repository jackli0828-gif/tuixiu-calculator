# 延迟退休年龄计算器

一个**纯静态、零依赖、零外部请求**的在线工具：输入出生年月与人员类型，即可算出改革后的法定退休年龄、具体退休时间、延迟月数，以及弹性提前 / 弹性延迟的可选区间，并提供男职工与两类女职工的「延迟退休年龄对照表」与政策解读 FAQ。

- 移动端优先、浅色主题、卡片式 UI（渐变主色 + 圆角 + 阴影）
- 全部代码内联在单个 `index.html` 中，**无需构建、无需后端、无需 npm 安装**
- 所有计算在浏览器本地完成，不收集、不上传任何个人信息
- 内置 2 个广告位容器（`class="ad-slot"`），可直接替换为 Google AdSense / 百度联盟代码

## 目录结构

## 算法依据与实现

### 政策依据

- **《全国人民代表大会常务委员会关于实施渐进式延迟法定退休年龄的决定》**
  （2024 年 9 月 13 日第十四届全国人民代表大会常务委员会第十一次会议通过，自 **2025 年 1 月 1 日**起施行）
- **《国务院关于渐进式延迟法定退休年龄的办法》**（配套实施办法）

### 渐进式延迟规则

| 人员类型 | 原法定退休年龄 | 改革后 | 起始出生年月 | 节奏 | 累计最多延迟 |
|---|---|---|---|---|---|
| 男职工 | 60 周岁 | 63 周岁 | 1965 年 1 月 | 每 **4** 个连续出生月延迟 1 个月 | **36** 个月（3 年） |
| 女职工（管理岗/专业技术岗） | 55 周岁 | 58 周岁 | 1970 年 1 月 | 每 **4** 个连续出生月延迟 1 个月 | **36** 个月（3 年） |
| 女职工（普通工人岗） | 50 周岁 | 55 周岁 | 1975 年 1 月 | 每 **2** 个连续出生月延迟 1 个月 | **60** 个月（5 年） |

### 计算公式

```
m = (出生年 − 起始年) × 12 + (出生月 − 起始月)     // 距起始年月的月数
delay = m < 0 ? 0 : min(封顶值, floor(m / 步长) + 1)

改革后退休年龄（月） = 原法定退休年龄 × 12 + delay
退休时间            = 出生年月 + 改革后退休年龄（月）
```

### 弹性退休区间

- **弹性提前退休**：需达到领取养老金最低缴费年限；提前时间距法定退休年龄最长不超过 **3 年**，且**不得低于原法定退休年龄**（男 60 / 女 55 / 女 50）。
  `最早可退时间 = max(原法定退休年龄时间, 法定退休时间 − 3 年)`
- **弹性延迟退休**：需与所在单位协商一致；延迟时间距法定退休年龄最长不超过 **3 年**。
  `最晚可退时间 = 法定退休时间 + 3 年`

### 最低缴费年限

自 **2030 年 1 月 1 日**起，按月领取基本养老金的最低缴费年限由 15 年**每年提高 6 个月**，逐步提高至 **20 年**。

## GitHub Pages 部署说明

1. **创建仓库**：在 GitHub 新建一个公开仓库（例如 `tuixiu-calc`）。
2. **上传文件**：将 `index.html`、`README.md`、`.nojekyll` 推送到仓库（`main` 分支根目录）。

   ```bash
   git init
   git add .
   git commit -m "feat: 延迟退休年龄计算器（纯静态单文件）"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/tuixiu-calc.git
   git push -u origin main
   ```

3. **开启 Pages**：仓库页面 → **Settings** → **Pages** → **Build and deployment**
   - Source 选择 **Deploy from a branch**
   - Branch 选择 `main`，目录选择 `/ (root)`
   - 点击 **Save**
4. **访问**：稍等 1–2 分钟，打开 `https://<你的用户名>.github.io/tuixiu-calc/` 即可。

> `.nojekyll` 文件用于跳过 Jekyll 构建，避免以 `_` 开头的目录/文件被忽略，同时加快部署速度。

### 部署后建议

- 将 `index.html` 中的 `<link rel="canonical">` 与 JSON-LD 中的 `url` 替换为你的真实 Pages 地址。
- 如需自定义域名：在仓库 `Settings → Pages → Custom domain` 填写域名，并在域名服务商处添加一条指向 `<你的用户名>.github.io` 的 `CNAME` 记录。
- 接入广告：把两个 `<div class="ad-slot">广告位</div>` 替换为你的广告代码即可（一个位于计算器下方，一个位于对照表下方）。
